## 📖 Executive Summary

**SUI Shopping Cart** is a state-of-the-art decentralized e-commerce marketplace that bridges the gap between Web2 user experience and Web3 security. Built on the **Sui Network**, it leverages the power of **Move** smart contracts to ensure transparent, trustless, and atomic transactions while interacting with a high-performance **Next.js** frontend.

Unlike traditional DApps, this platform offers a seamless "Shopee-like" retail experience, supporting high-concurrency "Retail Mode" sales (via Shared Objects) and individual asset ownership (via Kiosk), creating a robust hybrid environment for both digital and physical goods.

## 🚀 Key Highlights

*   **Hybrid Marketplace**: Supports both standard e-commerce (High Volume) and NFT-based listings (Unique Items).
*   **Atomic Transactions**: Payment and product transfer occur in a single atomic transaction—zero risk of fraud.
*   **Sui Move Powered**: Utilizes the best-in-class security models of the Move programming language.
*   **Web2 Speed, Web3 Trust**: Optimized Next.js frontend with Supabase indexing for instant page loads.
*   **Seller & Admin Dashboards**: Comprehensive tools for managing shops, products, and orders.

## 🔗 Quick Start

For a complete setup guide, please refer to [INSTALLATION.md](./INSTALLATION.md).

```bash

# Install dependencies

npm install

# Start the development server
npm run dev
```
